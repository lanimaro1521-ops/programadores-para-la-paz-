Sistema operativo:
Es el software principal del computador o servidor. Administra los recursos del sistema y permite que las aplicaciones se ejecuten correctamente.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web.

Aplicación server.js:
Es el archivo donde se encuentra el código del servidor. Define las rutas y las respuestas que recibirán los usuarios cuando accedan al servicio.

Puerto:
Es un canal de comunicación que utiliza el servidor para recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan información sobre la actividad y los eventos del servidor. Ayudan a detectar errores y monitorear el funcionamiento del sistema.
